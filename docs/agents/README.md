# Agent-Generated Documentation

This folder contains curated documentation generated by AI agents during development. Documents here are mirrored from `.agents/docs/` and committed to the repository for human review and historical record.

## Structure

| Folder | Purpose | Retention |
|--------|---------|-----------|
| `architecture/` | Architecture Decision Records (ADRs) | Permanent |
| `decisions/` | Key technical decisions with rationale | Permanent |
| `reviews/` | Significant code review summaries | 6 months |
| `reports/` | Milestone & phase completion reports | Permanent |

## Contributing

Agents write to `.agents/docs/` during work. The lead agent curates and copies significant documents here for commit.

## Co-Author Attribution

All documents in this folder follow the co-author convention:
```markdown
---
Co-authored-by: <model-id> <model-id>@users.noreply.github.com
```
